# 📊 Superstore Sales Dashboard

An end-to-end sales analytics dashboard built with Power BI, 
covering data cleaning, DAX modeling, and interactive visualization.

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (data cleaning)
- DAX (measures & calculations)

## 📌 What I Did
- Cleaned raw data: removed duplicates and handled missing values
- Built DAX measures: Total Sales, Total Profit, Profit Margin 
  (using CALCULATE and filter context)
- Designed KPI cards, trend charts, and category breakdowns
- Implemented hierarchical filtering (Year → Month → Day)

## 📈 Key Insights
- Identified seasonal sales patterns across 2015–2018
- Standard Class shipping accounts for 60% of order volume
- Technology, Furniture, and Office Supplies contribute 
  nearly equally to total revenue
